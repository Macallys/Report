# Assets del informe

assets/
├── 00-front-matter/          ← Logo UPC, Collaboration Insights
├── 01-capitulo-i/

│   └── lean-ux/              ← Lean UX Canvas
├── 02-capitulo-ii/
│   ├── competidores/         ← Landscape / logos
│   ├── entrevistas/
│   ├── needfinding/          ← Personas, Task Matrix, Journey, Empathy

├── 03-capitulo-iii/          ← Impact Map y artefactos de especificación
├── 04-capitulo-iv/
│   ├── ddd/                  ← EventStorming diseño, Context Map, BC Canvas
│   ├── architecture/         ← C4 / Deployment

├── 05-capitulo-v/
│   ├── style-guidelines/
│   ├── information-architecture/
│   ├── landing/
│   ├── applications/

## Convención de nombres

Usa nombres en kebab-case, por ejemplo:

- `upc-logo.png`
- `integrante-01.png`
- `lean-ux-canvas.png`
- `sprint-01-development.png`
